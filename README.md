# Projetos-FP

Projetos da unidade curricular de **Fundamentos da Programação** — LEIC-A, Instituto Superior Técnico, 2023/2024.

| Projeto | Tema | Descrição |
| --- | --- | --- |
| [Projeto 1](./Projeto%201) | Montanhas e Vales | Análise de um território de caminhos verticais e horizontais: cadeias de montanhas, vales e conexões entre interseções. |
| [Projeto 2](./Projeto%202) | Go | Jogo do Go para dois jogadores, com captura, regras do suicídio e do ko e contagem de territórios, construído sobre os TAD `intersecao`, `pedra` e `goban`. |

Cada projeto é resolvido num único ficheiro `.py`, usando apenas funcionalidades built-in do Python 3, e tem o enunciado e o README na respetiva pasta.
